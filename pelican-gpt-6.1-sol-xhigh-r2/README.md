# Pelican Coast Club

一个完全由代码搭建的 Three.js r160 海岸微缩世界：鹈鹕骑着珊瑚色自行车，经过灯塔、花丛、沙滩和帆船。

入口为 `index.html`，无需构建。将此目录部署到 GitHub Pages 即可。所有模型、纹理与声音均在本地生成，不请求 CDN、字体服务或其他外部资源。`vendor/` 保持原样。

## 操作

- 手机：单指旋转，双指缩放和旋转。请在画布外上下滑动页面。
- 桌面：拖动旋转，滚轮缩放。
- 点击「歇一会儿」暂停骑行，拖动「骑行节奏」调节速度。
- 「叮铃一下」播放合成车铃；右上角可单独开启海风声。
- 「等月亮 / 追太阳」切换昼夜；「回到这里」恢复视角。
- 「明信片」导出 1600 × 1400 PNG；手机保存行为由浏览器决定。
- 「骑行手记」打开小故事。键盘：空格暂停，B 车铃，N 昼夜。
- 尊重系统的「减少动态效果」设置：默认暂停骑行并停止环境循环动画。

## 本地预览

在允许监听本地端口的环境中，在此目录运行：

```sh
python3 -m http.server 8000
```

然后访问 `http://localhost:8000`。ES 模块应通过 HTTP(S) 加载。

## 文件

- `index.html`：页面结构和本地 importmap。
- `style.css`：响应式布局、昼夜配色、触屏控件。
- `app.js`：场景、几何建模、动画、交互、声音和图片导出。

## 验证记录与边界

`node --check app.js` 退出码为 0。在隔离的 Node 环境中，使用真实 Three.js r160 与 OrbitControls、替代 DOM 和渲染器，验证了场景构建、动画、暂停、速度、昼夜、弹窗、单指旋转、双指缩放和视角恢复。全部几何坐标为有限数值；场景约 22.7 万三角形、142 次可见网格绘制调用（不含 GPU 阴影额外绘制）。另用实际场景三角形生成了软件几何预览，以检查主角比例和构图。

当前执行环境禁止本地端口监听与浏览器进程所需的 socketpair 通信，无法完成浏览器截图、WebGL 着色器编译、真实音频/下载或安卓真机验证。上述逻辑检查不代表实际手机帧率或浏览器端完整验证。
